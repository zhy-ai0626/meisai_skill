# 静默陷阱：不报错，只出错数

竞赛里最危险的不是崩溃——崩溃会逼你去看。危险的是**程序跑通了、图也画了、数字也有了，但那个数是错的**，
或者**论文编译成功了、却违反了提交规则**。这类错误只能靠主动自查抓出来。
Stage 0（环境）、Stage 5（求解）、Stage 6（稳健性）、Stage 9（提交）各过一遍。

---

## 一、通用手段

### 1.1 先写恒等式，再看结果

给每个中间量找一条它必须满足的恒等式。恒等式不成立，说明要么算错了，要么用错了工具。

| 场景 | 该成立的恒等式 |
|---|---|
| 概率/分布 | 各类概率之和 = 1；CDF 单调、端点为 0 和 1 |
| 物理/机理 | 能量、质量守恒；方程两边量纲一致 |
| 种群/资源 | 数量非负；总量变化 = 流入 − 流出 |
| 分组/分段 | 各组之和 = 总数 |
| 优化 | 最优解处目标值 = 逐项重算的值；约束逐条代回都满足；整数变量真的是整数 |
| 前后两问 | 后一问在退化参数下应还原成前一问的结果 |
| 预测 | 训练期内的预测 ≈ 观测；外推不超出物理上限（奖牌总数、人口、面积） |

### 1.2 打印中间量，不要只看最终输出

估计器第一次上真数据时，打印中间量。最终输出"像个数"是最没有信息量的信号。

| 方法 | 该打印的中间量 |
|---|---|
| 回归 | 样本数、条件数、残差 RMS 与残差自相关 |
| 迭代优化/启发式 | 迭代次数、是否触界、多个初值/种子收敛到几个不同解 |
| ODE 数值解 | 步长、是否出现负值或发散、`solve_ivp` 的 `status` 与 `message` |
| 聚类 | 每簇样本数（有没有只有 1 个样本的簇）、不同 k 的轮廓系数 |
| 评价模型 | 每个指标归一化后的范围、权重之和、AHP 一致性比率 CR |

## 二、建模与数据陷阱（美赛高发）

### 2.1 时间序列用随机 K 折交叉验证（C 题）
- 现象：准确率高得漂亮。
- 根因：随机打乱后用"未来"预测"过去"，信息泄漏。
- 修复：按时间切分（滚动/末段留出）。2025C O 奖 2516178 专门写明用了 "last-block cross-validation"。

### 2.2 先标准化再划分训练/测试集
- 根因：测试集的均值方差泄漏进训练。修复：只用训练集拟合 scaler。

### 2.3 对时间序列做普通 Bootstrap 置信区间
- 根因：忽略自相关，区间偏窄。修复：块 Bootstrap 或模型残差重采样，并说明方法。

### 2.4 单位混用
- 现象：电池容量 mAh 与 Ah 混用、时间秒与小时混用，结果差 1000 或 3600 倍但曲线形状正常。
- 修复：Notations 表写单位，代码里变量名带单位后缀（`q_mah`、`t_h`）。

### 2.5 显式欧拉步长过大
- 现象：种群出现负数、振荡越来越大。
- 修复：用 `scipy.integrate.solve_ivp`（设 `rtol`/`atol`），并检查非负性。

### 2.6 熵权法遇到 0 或负值
- 现象：`log(0)` 产生 NaN，被 pandas 静默当成 0 或丢掉，权重悄悄改变。
- 修复：归一化平移到 (0, 1]，计算后断言权重无 NaN、和为 1。

### 2.7 AHP 不做一致性检验
- 修复：报告 CR，CR ≥ 0.1 时调整判断矩阵。

### 2.8 求解器"optimal"是松弛问题的最优
- 现象：整数规划返回小数解或状态是 `optimal_inaccurate`。
- 修复：检查求解状态、整数性与约束残差。

### 2.9 蒙特卡洛只跑一次
- 修复：多次运行（不同 seed），报告均值与区间；固定主 seed 保证可复现。

### 2.10a 同一类别两种写法（2026C 真实数据）
- 现象：`2026_MCM_Problem_C_Data.csv` 的 `celebrity_industry` 列里同时有 "Social Media Personality" 和 "Social media personality"。直接 `groupby` 会把同一行业切成两组，行业效应的估计悄悄变了，不报错。
- 修复：分组前 `.str.strip().str.lower()`；`scripts/scan_attachments.py` 会报 `case_collision`（本仓库开发时用这份数据实测扫出）。

### 2.10 外部数据口径不一致（`open_data_required`）
- 现象：两个来源的同一指标定义不同（名义 vs 实际 GDP、年度 vs 财年）。
- 修复：Data 小节逐个列出来源、定义与时间范围；合并前对重叠年份做一致性比对。

## 三、提交与排版陷阱

### 3.1 PDF 总页数 ≠ 计入上限的页数
- Report on Use of AI 不计入 25 页，但它在同一个 PDF 里。只看 PDF 页数会误判。
- `render_paper.py` 从 `main.aux` 读出解答页数单独报告；`check_compliance.py` 以 "Report on Use of AI" 所在页为界。

### 3.2 截止时间是美东时间
- 1–2 月美东是 UTC−5，北京是 UTC+8，**相差 13 小时**。2027 届停止修改是北京时间 **2 月 2 日 09:00**，不是 2 月 1 日晚上。

### 3.3 MiKTeX 按需装包会卡住、不报错
- 现象：`pdflatex` 停在加载某个宏包处，没有任何输出（在后台弹了一个安装确认窗口）。本仓库开发时实测：首次编译停在 `newtxtext.sty`。
- 修复：Stage 0 跑 `doctor.py` 的 `latex-smoke`（带超时）；缺包时用 `miktex packages install newtx` 等命令装好，或在 MiKTeX Console 里开启"自动安装缺失宏包"。本模板实测需要的包：newtx、xpatch、xstring、carlisle、binhex、fontaxes、fancyhdr、lastpage、tex-gyre。

### 3.4 图里的中文变方框
- matplotlib 遇到缺字只刷一条 findfont 警告，图照出。英文论文的图里不该有中文；用 `figures/starter.py` 起手。

### 3.5 官方模板的占位符没改
- 直接拿 COMAP 模板改的稿子，`\Team{1111111}`、`\Problem{ABCDEF}` 常被漏掉。`render_paper.py` 与 `check_compliance.py` 都会查。

### 3.6 Word 导出的 PDF 带作者名
- 文件属性里的作者是本机用户名，可能就是真名。`check_compliance.py` 查 `/Author`。

### 3.7 PDF 里的连字
- 从 PDF 复制出来的 "ﬁ"、"ﬂ" 是连字字符，搜 "fi" 搜不到。核对 PDF 文本时注意（`check_compliance.py` 的关键检查不依赖含 fi/fl 的词）。
