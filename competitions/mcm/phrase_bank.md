# 英文句式库（phrase bank）

> 按论文章节组织的常用英文句式。标 ★ 的是 O 奖 Summary 中高频出现的句式（统计自约 250 篇 O 奖论文的 Summary，
> 句首三词与四词组合的出现篇数）；其余是写作常用表达。**句式是骨架，内容要具体**：
> 每个句子后面都应该接你自己的数值和对象，不要整句套用。

## 1. Summary / Introduction 开场

| 用途 | 句式 |
|---|---|
| ★ 点题 | In this paper, we develop / establish / propose [model] to [goal]. |
| 背景一句 | [Object] has become [trend], with [concrete number] in [year]. |
| 引出挑战 | However, [difficulty] makes it hard to [task]. |
| 目标 | To [address the problem], we ... / Our goal is to ... |
| 总体框架 | We build [N] models: Model I for [purpose] and Model II for [purpose]. |
| 用户对象 | To assist [stakeholder] in [decision], we ... |

## 2. 逐 Task 叙述

| 用途 | 句式 |
|---|---|
| ★ 分任务 | For Task 1, we ... / In Task 2, we ... / Regarding the third problem, ... |
| ★ 基于 | Based on [theory / data / Model I], we ... |
| ★ 目的状语 | In order to [verb], we [method]. |
| ★ 递进 | In addition, we ... / Furthermore, ... / On this basis, we ... |
| ★ 顺序 | First, ... Then, ... After that, ... Finally, ... |
| 方法 + 结果合一句 | Using [method], we find that [result with number]. |
| 指向图表 | (see Figure 4) / as shown in Table 2 / Results are presented in Section 5.2. |

## 3. 报告结果

| 用途 | 句式 |
|---|---|
| ★ 结果显示 | The results show that [finding]. / The result shows ... |
| ★ 发现 | We find that ... / It is found that ... |
| 带数字 | [Metric] reaches [value], which is [x]% higher than [baseline]. |
| 预测 | We predict that [entity] will [outcome] by [year], with a 95% confidence interval of [a, b]. |
| 比较 | Compared with [baseline], our model reduces [error] from [a] to [b]. |
| 排序 | The top three [items] are A (x), B (y), and C (z). |
| 解读 | This indicates that ... / This suggests that ... / This means that, for [stakeholder], ... |
| 谨慎 | The evidence is consistent with ... but does not establish causality. |

## 4. 假设与符号

| 用途 | 句式 |
|---|---|
| 假设 | We assume that [statement]. |
| 理由 | *Justification:* [data / literature / order-of-magnitude argument]. |
| 放松 | This assumption is relaxed in Section [k]. |
| 符号 | The symbols used in this paper are listed in Table 1. |
| 定义 | Let $x_i$ denote [meaning] (unit). |

## 5. 模型建立与求解

| 用途 | 句式 |
|---|---|
| 从简到繁 | We start from the simplest description of [process] and then incorporate [factor 1], [factor 2]. |
| 引入机理 | According to [law/theory], [quantity] is proportional to [quantity], so ... |
| 方程 | The dynamics of [quantity] are governed by |
| 求解 | We solve the system numerically using [method] with [parameter settings]. |
| 参数来源 | Parameter values are taken from [source] [n] and listed in Table 3. |
| 标定 | We calibrate [parameter] by minimizing [loss] on [data]. |

## 6. 验证、灵敏度、稳健性

| 用途 | 句式 |
|---|---|
| ★ 灵敏度 | Finally, sensitivity analysis shows that [conclusion] remains unchanged when [parameter] varies within ±[x]%. |
| 最敏感参数 | The model is most sensitive to [parameter]: a 10% increase leads to a [y]% change in [output]. |
| 稳健 | Our recommendation is robust to [perturbation] within [range]. |
| 交叉验证 | Using time-series cross-validation, the model achieves an RMSE of [v] (R² = [r]). |
| 一致性 | Our estimates are consistent with [observed outcome] in [k] of [n] cases. |

## 7. 优缺点与推广

| 用途 | 句式 |
|---|---|
| ★ 节标题 | Strengths and Weaknesses of the Model |
| 优点 | The model captures [mechanism], which allows ... / All parameters have clear physical meaning. |
| 缺点 | The model neglects [factor]; this may overestimate [quantity] when [condition]. |
| 改进 | This could be addressed by incorporating [data / mechanism]. |
| 推广 | The framework can be applied to [other setting] by replacing [module/parameter]. |

## 8. Letter / Memo

| 用途 | 句式 |
|---|---|
| 目的 | This memo summarizes our findings on [topic] and recommends [action]. |
| 写信缘由 | We are writing to share the results of our analysis of [topic]. |
| 发现 | Our analysis shows that [finding in plain language, with one number]. |
| 建议 | We recommend that you [action], which is expected to [effect]. |
| 取舍 | The main trade-off is [cost] versus [benefit]. |
| 风险 | The key risk is [risk]; we suggest [mitigation]. |
| 收尾 | We would be glad to provide further details. / Thank you for your consideration. |

## 9. AI 使用的正文引用（COMAP 要求 inline citation）

| 用途 | 句式 |
|---|---|
| 润色 | The language of Section 3 was polished with the assistance of ChatGPT [12]. |
| 代码 | Parts of the plotting code were drafted with GitHub Copilot [13] and verified by the team. |
| 翻译 | Portions of this paper were translated from Chinese using DeepL [14]. |

## 10. 少用的表达

| 别写 | 改成 |
|---|---|
| Our model is perfect / very good | Our model reduces the error to [x] |
| It is obvious that | （直接陈述结论） |
| a lot of | many / a large number of [具体数字] |
| In a word, | In summary, |
| With the development of society, | （删掉，换成具体背景事实） |
| make a conclusion | draw a conclusion |
