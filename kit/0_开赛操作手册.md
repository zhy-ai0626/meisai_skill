# 开赛操作手册（美赛 MCM/ICM）：拿到题之后怎么做

核心问题：**能不能直接把今年的六道题丢给 Claude Code + skill？** 能。但它不是解题机器——下面写清每一步的命令、它能做什么、不能做什么。

时间以 `competitions/mcm/current_rules.md` 当届核对结果为准（2027 届：北京时间 **1 月 29 日周五 06:00** 开赛，**2 月 2 日周二 09:00** 停止修改，10:00 前提交）。

---

## 一、赛前一周：装好并自检

```bash
git clone https://github.com/zhy-ai0626/meisai_skill ~/.claude/skills/mcm-icm
S=~/.claude/skills/mcm-icm
pip install -r $S/templates/shared/requirements.txt

# 完整预检：会真编译一次 smoke.tex（Summary Sheet 版式 + newtx 字体）
python $S/scripts/doctor.py --require-renderer --require-modeling

# 绘图环境自检：六段英文图全出才算通（同时出灰度校样）
python $S/figures/starter.py --out ./_figcheck

# 可编辑流程图（需要 python-pptx）
python $S/figures/flow_pptx.py --output ./_figcheck/overview.pptx --preview
```

**MiKTeX 用户注意**：首次编译会按需下载宏包，后台弹出的确认窗口会让 `pdflatex` 卡住且不报错。
`latex-smoke` 失败时按 doctor 的提示装包，本模板实测需要：newtx、xpatch、xstring、carlisle、binhex、fontaxes、fancyhdr、lastpage、tex-gyre。
（命令：`miktex packages install newtx` 等；或在 MiKTeX Console 里开启"自动安装缺失宏包"。）

还要准备好：
- **队伍控制号**（报名后 COMAP 发放的 7 位数）与 **Advisor ID**（提交表单要用）
- 分工：建模 / 编程 / 英文写作各有主责；约定四个晚上的轮班睡眠

## 二、开赛当天

### Step 1　建工作目录，把六道题放进去

```
mcm2027/
├── problems/            ← 2027_MCM_Problem_A.pdf ... 2027_ICM_Problem_F.pdf，C 题数据
└── （skill 会自己建 state/ results/ figures/ paper_workspace/）
```

### Step 2　在该目录启动 Claude Code，说：

```
开始美赛建模。六道题在 problems/ 下，我们 3 人：A 擅长微分方程，B 擅长 Python 和机器学习，
C 英语最好负责写作。控制号 27xxxxx。
```

skill 会：
1. 读 `current_rules.md`，核对 COMAP 官网有无更新
2. Stage 0：初始化 `state/decision_log.json`，跑编译链 smoke，**逐题抄录交付物要求**（letter/memo、读者、篇幅）
3. Stage 1：六道题做同构卡片 + 六维对比矩阵，给出推荐，**问你选哪道**
4. 之后每个关键决策都用编号问题问你；你只需回复数字

**目标：北京时间周五中午前定题。**

### Step 3　不想走完整 10 阶段时，用独立提示词

见 `2_提示词模板.md`，按阶段复制粘贴即可。

### Step 4　Day 2 起英文写作并行

写作主不要等模型做完：Introduction、Assumptions、Notations、各模型的方法描述可以先写。
最后 8 小时只做装配、Summary Sheet 定稿、合规检查。

### Step 5　提交前必跑

```bash
# Stage 2（有数据就跑）：数据体检 + 口径闸门
python $S/scripts/scan_attachments.py problems/ --json > state/scan.json
python $S/scripts/check_data_decisions.py --decision-log state/decision_log.json --scan state/scan.json

# Stage 6 与 Stage 9：自检承诺与 Weaknesses 是否都了结（英文论文也能扫）
python $S/scripts/check_selfaudit.py --ledger state/self_audit.json --workspace paper_workspace/ --results results/

# Stage 8：AI 披露 → 渲染（报告解答页数，超 25 页直接 FAIL）
python $S/scripts/render_ai_usage.py --paper-workspace paper_workspace/
python $S/scripts/render_paper.py --workspace paper_workspace/ --output-dir paper_output/

# Stage 9：数字可追溯 / 图与交叉引用 / 合规
python $S/scripts/check_numbers.py --paper paper_output/main.tex --results results/
python $S/scripts/check_figures.py --workspace paper_workspace/ --figures figures/ --topic B
cp paper_output/main.pdf paper_output/27xxxxx.pdf
python $S/scripts/check_compliance.py --paper paper_output/27xxxxx.pdf
```

`check_compliance.py` 退出码非零 = 有 FAIL，**不要提交**。

### Step 6　提交

<https://forms.comap.org/241335097294056>：填控制号、Advisor ID、题号、**AI uses statement（Yes/No）**，上传 `<控制号>.pdf`（< 25 MB）。不发确认邮件；每队只交一次。

## 三、它能做什么，不能做什么

### 能做
- 把六道题读完、抄出交付物、做对比矩阵，帮你定题
- 按题型给方法主线（依据 279 篇 O 奖论文的方法分布），从最简模型推进
- 写代码、跑数值、出英文图（灰度可读）、维护决策日志（换会话可续跑）
- 按 COMAP 规则装配论文：Summary Sheet 页眉、目录、letter/memo、AI 报告、每页控制号与页码
- 提交前机器检查：25 页、12pt、匿名、英文、交付物、AI 披露、数字可追溯

### 不能做
- 保证模型对、保证拿奖——实证分位只是"O 奖论文长什么样"
- 替你判断题意里的模糊处——它会把这类问题写进 `open_questions` 问你
- 替你核对 AI 生成的参考文献——必须人工逐条打开

### 一条容易用反的地方
**用了 skill 就是用了 AI。** COMAP 政策要求如实披露：`decision_log.compliance.ai_usage` 全程记录，`render_ai_usage.py` 生成 Report on Use of AI。2024、2025 年约 34%、42% 的 O 奖论文附了 AI 报告——如实披露不影响拿奖，未披露才是风险。

## 四、两个已知的坑

1. **页数看错**：PDF 总页数含 AI 报告，不计入 25 页。以 `render_paper.py` 报的"解答页数"为准。
2. **时区算错**：1–2 月美东比北京晚 13 小时。周一晚上 8 点（美东）= 周二早上 9 点（北京）。
