# 官方文件（不随 skill 分发）

COMAP 的规则、题面与模板版权属于 COMAP，本仓库**不打包原件**，只记录去哪里拿、拿来做什么。
`competitions/mcm/current_rules.md` 记录了核对过的条款与核对日期。

| 文件 | 从哪里拿 | 用途 |
|---|---|---|
| Rules, Registration and Instructions | <https://www.contest.comap.com/undergraduate/contests/mcm/instructions.php> | 25 页上限、页眉、字号、匿名、时间表——Stage 0 与 Stage 9 核对 |
| `Contest_AI_Policy.pdf`（Use of AI Tools in COMAP Contests） | 随当届题目包分发；也在 instructions 页面链接 | Report on Use of AI 的格式与要求 |
| `MCM-ICM_SubProcess.pdf`（Submission Walk Through） | 随当届题目包分发 | 提交表单字段、文件名与大小 |
| `MCM-ICM_Summary.tex` / `.docx`（Summary Sheet 模板） | 随当届题目包分发；instructions 页面有 Word/LaTeX 下载链接 | 官方第 1 页版式。本仓库 `templates/latex/mcm/main.tex` 按同样版式原创实现 |
| 当届六道题 PDF 与数据 | 开赛时从 COMAP 官网下载 | Stage 0 预扫、Stage 1 选题 |
| 历年结果与 Outstanding 名单 | `https://www.contest.comap.com/undergraduate/contests/mcm/contests/<year>/results/` | 核对 O 奖论文身份 |

Outstanding 论文全文在 Mathmodels.org（会员）发布；本仓库只分发从中统计出的描述性数据（`competitions/mcm/empirical.json`）。
